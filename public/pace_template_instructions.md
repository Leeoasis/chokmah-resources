# PACE Excel Template Instructions

## Download Template
Create an Excel file (.xlsx) with the following structure:

### Metadata Section (Rows 1-6)
| Column A          | Column B (Your Data)  |
|-------------------|-----------------------|
| Title             | Math Quiz Grade 8     |
| Description       | Algebra basics test   |
| Subject           | Mathematics           |
| Grade Level       | Grade 8               |
| Passing Score     | 60                    |
| Time Limit (min)  | 45                    |

### Questions Section (Starting Row 8)
Row 8 should be the header row:
| Question # | Question Text | Option 1 | Option 2 | Option 3 | Option 4 | Option 5 | Correct Answer | Points |

Row 9 onwards - your questions:
| 1 | What is 2+2? | 3 | 4 | 5 | 6 | | 4 | 1 |
| 2 | Capital of France? | London | Paris | Berlin | Rome | | Paris | 1 |

## Important Notes:
- You MUST have at least 2 options per question
- Options 3, 4, 5 are optional (leave blank if not needed)
- Correct Answer must EXACTLY match one of the options
- Points default to 1 if left blank
- Leave row 7 empty
- Do not skip question numbers

## Upload
1. Save your file as .xlsx or .xls
2. Go to Admin Panel > PACEs
3. Click "Upload File (JSON/Excel)"
4. Select your Excel file
5. Click Upload
